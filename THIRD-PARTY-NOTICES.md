# Third-Party Notices

WardSweep incorporates third-party software. This document lists those components and
their licences.

The complete lists are generated from the lock files, and CI fails when either
is out of date:

- [`licenses/rust.md`](licenses/rust.md) — every third-party crate in
  WardSweep's binaries, from `Cargo.lock`, with the licence each is used under
  and the licence text it was published with. Generated by `cargo about`
  (configured in `about.toml` and `about.hbs`).
- [`licenses/dotnet.md`](licenses/dotnet.md) — every NuGet package the
  interface ships with, from `ui/WardSweep.UI/packages.lock.json`, and
  Velopack, whose installer and updater every release carries; with each
  package's licence, copyright, licence file and the third-party notices it
  carries itself. Analysers and other development-only packages are listed as
  left out.

After changing a dependency, regenerate both and commit the result:

```
cargo fetch --locked
dotnet restore WardSweep.sln --locked-mode
dotnet tool restore
python .github/scripts/notices.py
```

`rust-ci.yml` and `dotnet-ci.yml` run the same script with `--check`, and it
also fails if `about.toml` stops accepting exactly what `deny.toml` allows.
Every release carries this file, both lists and `LICENSE`.

Licence identifiers use [SPDX](https://spdx.org/licenses/).
